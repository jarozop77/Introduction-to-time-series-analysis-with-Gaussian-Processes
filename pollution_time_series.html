Daily PM2.5 Time Series with Gaussian Processes

This analysis uses a dataset from the daily concentration of of PM2.5 in the air at one particular monitoring station. The data is at the dataset is located at data/station_complete.csv. The response is transformed to the logarithm scale since it stabilizes the positive, right-skewed concentration scale.

For this analysis you will need the following R packages

Let’s explore the components of the time series: systematic + residual component. We can estimate the trend using a loess smoother. The residuals are the difference between the observed log PM2.5 and the estimated trend.

d$trend <- predict(
  loess(log_pm25 ~ day, data = d, span = 0.2)
)
d$residual <- d$log_pm25 - d$trend

The functions ‘decompose’ and ‘stl’ are also available for decomposition, but they are designed for seasonal data. Since we only have one year of daily data, we cannot reliably estimate a seasonal component. These functions are available in the R package stats, they need an object of the class ts (time series). The following code shows how to use the stl function to decompose the log PM2.5 series into trend, seasonal and remainder components. However, for this precise example is not recommended to use it since we only have one year of data.

In ‘decompose()’, type chooses how the components combine: - Additive: series = trend + seasonal + remainder. Use it when seasonal swings are roughly the same size over time. - Multiplicative: series = trend × seasonal × remainder. Use it when seasonal swings grow or shrink with the series level; the data must be positive. In ‘stl()’, s.window = “periodic” makes the seasonal pattern the same for every cycle. With frequency = 7, it estimates one weekly pattern and repeats it unchanged. This is different from STL’s numeric s.window, which controls how flexibly the seasonal pattern can change over time.

pm_ts <- ts(d$log_pm25, frequency = 7)

parts <- decompose(pm_ts, type = "additive")
plot(parts)

part <- stl(pm_ts, s.window = "periodic", robust = TRUE)
plot(part)

The ACF (left) starts very high and declines gradually over many lags. Even after removing a linear trend, nearby residuals remain strongly correlated, so the series still has substantial temporal dependence. The PACF (right) has a dominant spike at lag 1 and a smaller one at lag 2, while most later spikes stay within the blue confidence limits.

ML fits for five models

Autoregressive models

d = as.data.frame(d)
fit1<- spaMM::fitme(
  log_pm25 ~ day + AR1(1 | day),
  data = d,
  family = gaussian(),
  method = "ML"

Hold-out validation

We reserve the final 20% of the daily PM2.5 observations as a hold-out test set. The models are fitted using only the first 80% of the time series, then used to predict the held-out period. We compare their predictive accuracy using test-set RMSE on the log PM2.5 scale; lower RMSE indicates predictions closer to the observed values.

# Hold out the last 20% of observations
n_train <- floor(0.8 * nrow(d))
train <- d[1:n_train, ]
test  <- d[(n_train + 1):nrow(d), ]

# Fit each model using training data only
fit1_train <- spaMM::fitme(
  log_pm25 ~ day + AR1(1 | day),
  data = train,
  family = gaussian(),
  method = "ML"
)

fit2_train <- spaMM::fitme(
  log_pm25 ~ day + Matern(1 | day),
  data = train,
  family = gaussian(),
  fixed = list(nu = 0.5),
  method = "ML"
)

fit3_train <- spaMM::fitme(
  log_pm25 ~ day + Matern(1 | day),
  data = train,
  family = gaussian(),
  fixed = list(nu = 1.5),
  method = "ML"
)

fit4_train <- spaMM::fitme(
  log_pm25 ~ day + Matern(1 | day),
  data = train,
  family = gaussian(),
  fixed = list(nu = 2.5),
  method = "ML"
)

# Predict the held-out observations
predictions <- data.frame(
  day = test$day,
  observed = test$log_pm25,
  AR1 = predict(fit1_train, newdata = test),
  Matern_05 = predict(fit2_train, newdata = test),
  Matern_15 = predict(fit3_train, newdata = test),
  Matern_25 = predict(fit4_train, newdata = test)
)

# Test-set RMSE
rmse <- function(actual, predicted) {
  sqrt(mean((actual - predicted)^2, na.rm = TRUE))
}

data.frame(
  model = c("AR1", "Matern nu=0.5", "Matern nu=1.5", "Matern nu=2.5"),
  RMSE = c(
    rmse(predictions$observed, predictions$AR1),
    rmse(predictions$observed, predictions$Matern_05),
    rmse(predictions$observed, predictions$Matern_15),
    rmse(predictions$observed, predictions$Matern_25)
  )
)
